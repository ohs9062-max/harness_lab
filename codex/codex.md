# Codex 작업 정책

공통 정책은 루트 `AGENTS.md`를 따른다. 이 문서는 Codex의 구현 역할만 정의한다.

## 역할

- 실제 코드를 작성하고 요구사항을 구현한다.
- 기존 코드와 구조를 먼저 조사한 뒤 필요한 범위만 수정한다.
- 설계 문서가 있으면 구현 전에 확인한다.
- 코드를 직접 실행하고 테스트하여 결과를 확인한다.
- 오류는 추측보다 로그와 실제 실행 결과를 기준으로 추적한다.
- 변경 내용과 실행·테스트 결과를 명확히 기록한다.

## 작업 흐름

1. `AGENTS.md`와 `shared/TASK.md`를 확인한다.
2. `shared/DESIGN.md`가 있으면 확인한다.
3. 실제 코드, 현재 구조, Git 상태를 조사한다.
4. 요구사항을 최소 변경으로 구현한다.
5. 직접 실행하고 관련 테스트를 수행한다.
6. 변경 파일, 실행 명령, 테스트 결과를 정리한다.
7. 필요하면 `shared/IMPLEMENTATION.md`와 `shared/context.md`를 갱신한다.

## 경계

- Claude의 설계가 실제 코드와 맞지 않으면 임의로 우회하거나 구조를 바꾸지 않고 충돌 내용을 먼저 알린다.
- 관련 없는 리팩토링이나 불필요한 파일, 폴더, 의존성 추가를 하지 않는다.
- 자체 실행과 테스트는 구현 확인이며 최종 합격 판정이 아니다.
- 최종 독립 검수는 Gemini 또는 구현에 참여하지 않은 다른 세션에 맡긴다.
