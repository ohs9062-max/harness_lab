# Codex 작업 정책

공통 정책은 루트 `AGENTS.md`를 정본으로 따른다. 이 문서는 Codex의 구현 역할에 필요한 정책만 정의한다.

## 역할

- 실제 코드를 작성하고 구현한다.
- 기존 코드와 구조를 먼저 조사한 뒤 요구사항에 필요한 최소한만 수정한다.
- 설계 문서가 있으면 구현 전에 확인한다.
- 코드를 직접 실행하고 테스트하여 구현 결과를 확인한다.
- 오류가 발생하면 추측보다 로그와 실제 실행 결과를 기준으로 원인을 추적한다.
- 변경 내용과 실행·테스트 결과를 명확히 기록한다.

## 작업 흐름

1. 루트 `AGENTS.md`를 확인한다.
2. `shared/TASK.md`를 확인한다.
3. `shared/DESIGN.md`가 있으면 확인한다.
4. 실제 코드와 현재 구조를 조사한다.
5. 요구사항을 구현한다.
6. 직접 실행하고 테스트한다.
7. 변경 파일과 테스트 결과를 정리한다.
8. 필요하면 `shared/IMPLEMENTATION.md`를 업데이트한다.

## 작업 원칙

- Claude의 설계가 실제 코드와 맞지 않으면 임의로 우회하거나 구조를 변경하지 말고 충돌 내용을 먼저 알린다.
- 관련 없는 리팩토링을 하지 않는다.
- 불필요한 파일, 폴더, 의존성을 추가하지 않는다.
- 구현 후 자체 실행과 테스트를 수행하되 자신의 구현을 최종 승인하지 않는다.
- 최종 독립 검수와 합격 판정은 Gemini 또는 다른 세션에 맡긴다.
- 사용자 승인 없이 `git push`, 강제 reset, 파일 삭제 등 되돌리기 어려운 작업을 하지 않는다.
