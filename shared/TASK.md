# 현재 작업

## 목표

여러 AI가 설계, 구현, 독립 검수를 분담하고 파일로 상태를 인계할 수 있는 하네스 엔지니어링 환경을 구축한다.

## 범위

- 루트 `AGENTS.md`를 공통 정책의 정본으로 유지한다.
- `claude/`, `codex/`, `gemini/`에 역할별 작업 정책을 둔다.
- `shared/`에 작업 목표, 설계, 구현 결과, 검수 결과, 세션 인계를 기록한다.
- 실제 코드 실험은 기본적으로 `demo/`에서 수행한다.

## 완료 기준

- 각 AI의 책임과 경계가 중복 없이 구분되어 있다.
- Claude 설계 → Codex 구현·자체 테스트 → Gemini 독립 검수 흐름이 문서화되어 있다.
- 새 세션이 공유 문서만 읽고 현재 상태와 다음 작업을 파악할 수 있다.
- 자체 테스트와 최종 합격 판정이 분리되어 있다.
- 위험한 Git 작업은 사용자 승인 없이 수행하지 않도록 명시되어 있다.

## 현재 상태

- 환경 문서 구성 및 검수를 완료했다.
- 아래 첫 데모 과제로 파이프라인을 시험 운영할 준비가 되었다.

## 다음 과제: 첫 데모 — 파이프라인 시험 운영

`demo/` 디렉토리에서 간단한 과제를 하나 수행하여
Claude 설계 → Codex 구현 → Gemini 독립 검수 → 사용자 판단 흐름을 실제로 검증한다.

과제 예시 (사용자가 구체적으로 지정):

- 간단한 CLI 도구
- 단일 파일 유틸리티
- 기존 프로젝트의 작은 기능 추가

이 과제의 목적은 코드 자체보다 **하네스 파이프라인이 실제로 작동하는지 확인**하는 것이다.
