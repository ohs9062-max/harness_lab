# 설계 기록

## 작성 정보

- 작성자: Codex
- 모델: 확인 불가
- 역할: 문서 구조 설계 및 구현
- 작성일: 2026-08-21
- TASK-ID: TASK-2026-08-21-001

## 설계 상태

- 사용자가 직전 분석에서 제안한 두 문서와 연결 수정안을 승인했다.
- 별도 Claude 설계 문서는 없으며, 승인된 제안을 최소 설계 기준으로 사용한다.

## 최소 설계

- `CHANGELOG.md`는 하네스 자체의 의미 있는 변화만 append-only로 누적한다.
- `shared/README.md`는 shared 문서의 운영 규약과 초기화 기준만 담당한다.
- 정책 정본은 계속 `AGENTS.md`, 코드 원칙 정본은 `ENGINEERING_POLICY.md`, 사용자 운영 절차 정본은 `WORKFLOW.md`로 유지한다.
- 자동화, 위키링크 지식 그래프, daily/inbox/outbox 체계는 현재 규모에 비해 과하므로 도입하지 않는다.

## 검증 기준

- 새 문서와 기존 문서 사이에 책임 중복이나 상충 문구가 없는지 검색한다.
- 상대경로로 언급한 문서가 실제 존재하는지 확인한다.
- 모든 shared 문서의 TASK-ID와 작성일을 대조한다.
- 실제 Git diff가 승인 범위에 한정되는지 확인한다.
