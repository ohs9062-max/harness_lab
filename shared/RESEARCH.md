## ID 규칙

새 TASK에서는 원본 Claim과 Source에 작성 AI namespace를 사용한다.

- canonical prefix: CLAUDE, CODEX, GEMINI
- Claim: <AGENT>-C001
- Source: <AGENT>-S001
- 다른 AI·세션: 식별 가능한 짧은 prefix를 사용한다. 예: REVIEWER2-C001, AGENT4-S001
- 모델명은 ID에 넣지 않고 문서 작성 정보에서 관리한다.

단일 RESEARCH도 namespace 형식을 권장한다. 기존 TASK와 Git history의 C-001/S-001은 변경하지 않는다.
PARALLEL RESEARCH에서는 각 AI가 자기 namespace에서 독립적으로 번호를 부여하며 다른 AI 번호를
확인하거나 맞추지 않는다.
