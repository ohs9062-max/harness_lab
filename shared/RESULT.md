# 작업 결과

여기에는 한 작업 주기의 최종 상태만 간결하게 정리한다. 세부 근거는 설계, 구현, 검수 문서를 참조한다.

## 결과

- 상태: 환경 문서 구성 완료, 독립 검수 대기
- 사용자 최종 판단: 대기

## 산출물

- 설계: `shared/DESIGN.md`
- 구현 및 자체 테스트: `shared/IMPLEMENTATION.md`
- 독립 검수: `shared/REVIEW.md`
- 세션 인계: `shared/context.md`

## 남은 사항

- 실제 데모 과제를 정한 뒤 역할별 흐름을 한 차례 실행해 환경을 검증한다.
- 독립 검수 결과를 바탕으로 사용자가 최종 완료 여부를 판단한다.
