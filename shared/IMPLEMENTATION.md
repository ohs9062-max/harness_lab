# 구현 기록

## TASK-ID

(현재 작업의 TASK-ID를 적는다)

Codex가 실제 구현과 자체 검증 결과를 기록한다. 이 문서는 최종 승인서가 아니다.

## 구현 내용

- 요구사항별 구현 결과와 중요한 판단을 적는다.

## 변경 파일

- 파일별 변경 이유를 적는다.

## 실행 및 테스트

- 실행한 명령, 결과, 확인한 동작을 적는다.
- 실패하거나 실행하지 못한 검증도 숨기지 않고 적는다.

## 설계와의 차이

- 설계 변경이나 충돌이 있었다면 원인과 합의 여부를 적는다.

## 검수 요청 사항

- Gemini가 독립적으로 확인해야 할 위험과 조건을 적는다.
